# 🚀 Neon Space Shooter

A dynamic 2D arcade space shooter built using HTML5 Canvas and Vanilla JavaScript.

## 🎮 About the Game

Neon Space Shooter is a real-time browser-based arcade game where the player controls a spaceship, avoids incoming enemies, and destroys them using projectiles.

The project focuses on implementing real-time game mechanics using the HTML5 Canvas API and JavaScript.

## ✨ Features

- Real-time player movement
- Keyboard controls
- Enemy spawning
- Shooting mechanics
- Collision detection
- Score system
- Lives/health system
- Game states
- High-score persistence using localStorage
- Progressive difficulty
- Particle effects
- Sound effects
- Responsive canvas

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Canvas API
- Web Audio API
- localStorage

## 🧠 Core Concepts

- requestAnimationFrame game loop
- Delta time
- 2D collision detection
- Object-oriented programming
- Event-driven input handling
- Game state management
- Browser storage

## 🚀 Running Locally

1. Clone the repository
2. Open the project in VS Code
3. Open `index.html` in a browser
